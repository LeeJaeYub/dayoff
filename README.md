# 🎈 한국 연차 최적화 계산기 (Toss Style)

사용자가 보유한 남은 연차 일수를 설정하면, 공휴일과 주말 사이에 연차를 최적 배치하여 **"최소 연차로 최대 연속 휴일"**을 만드는 방법을 계산해 주는 완전 정적 웹사이트입니다.

토스(Toss)의 디자인 언어 — **넉넉한 여백, 명확한 정보 위계, 즉각적인 인터랙션, 부드러운 애니메이션 및 미세 피드백 사운드**를 담아 기획 및 설계되었습니다.

---

## ✨ 핵심 기능 및 UX 특징
1. **🎡 3D 세로형 스크롤 드럼 피커 (Scroll Picker):** 모바일 터치와 드래그에 최적화되어 스크롤 시 아날로그 느낌의 경쾌한 "틱, 틱" 소리와 함께 직관적으로 연차 일수를 선택할 수 있습니다.
2. **🏆 가성비 극대화 효율 곱하기 배지:** 단순히 날짜만 나열하는 대신 `연속 휴일 일수 ÷ 연차 사용일수` 공식에 따른 **'효율 배지'**를 노출하여 가장 혜택이 큰 일정을 단번에 찾게 해줍니다.
3. **📅 실시간 반응형 아코디언 달력:** 추천 연차 카드를 클릭하면 하단 달력에서 해당 연차 사용 일수(Toss Blue)와 공휴일/주말들이 아름답고 부드러운 Ripple 효과와 함께 연동 강조됩니다.
4. **🔊 무의존성 Web Audio API 사운드 신디사이저:** 외부 무거운 mp3 에셋 다운로드 없이 브라우저 내장 오디오 노드를 동적으로 프로그래밍하여 프리미엄 클릭 피드백 톤("톡", "샤링~")을 재생합니다.
5. **🔒 100% 로컬 프라이버시 보호:** 모든 연차 계산은 방문자 기기 내부(Client-side) 브라우저 메모리 상에서만 동작하며, 외부 API 연동이나 서버 백엔드 전송이 일절 존재하지 않는 안전한 서버리스 구조입니다.

## 🛠 기술 스택
- **프론트엔드:** 순수 Vanilla HTML, CSS (Pretendard 폰트), ESM JavaScript
- **백엔드:** 없음 (No Server, No Cloudflare Workers, No database)
- **데이터:** 사전에 수집된 로컬 정적 JSON 파일 (`data/holidays.json`) 사용
- **호스팅/배포:** Cloudflare Pages (GitHub 리포지토리 자동 푸시 배포 연동)

## ⚙️ 로컬 개발 및 실행 방법

### 1. 웹 서버 실행 (실시간 브라우저 테스트)
본 프로젝트는 ES Module(`import/export`)을 사용하므로, 브라우저 보안 정책상 로컬 파일(`file://`)로 직접 열면 모듈 에러가 발생합니다. 반드시 가벼운 로컬 개발용 웹 서버로 구동하셔야 합니다.

#### 방법 A: Node.js 내장 서버 사용 (추천 - 추가 설치 없음)
Node.js가 설치되어 있다면 프로젝트 루트 폴더에서 아래 명령어로 아주 간단하게 구동할 수 있습니다.
```bash
# Node.js 패키지 실행기를 사용해 즉석에서 정적 서버 실행
npx servor . --port 8080
```
그 후 브라우저에서 `http://localhost:8080` 으로 접속하세요.

#### 방법 B: VS Code Live Server 확장 사용
VS Code를 사용 중이시라면 `Live Server` 확장을 설치한 후, 하단의 `Go Live` 버튼을 클릭하여 실행할 수 있습니다.

## 📅 공휴일 데이터 (`data/holidays.json`) 갱신 방법

기본적으로 `2026년` 및 `2027년` 법정 공휴일/대체공휴일 고정밀 데이터가 `data/holidays.json`에 미리 하드캐싱 형식으로 들어가 있으므로, **추가 세팅 없이 즉시 가동이 가능**합니다.

만약 대한민국 정부가 임시공휴일을 새로 발표하는 등 데이터를 갱신해야 하는 상황이 오면 아래 절차대로 API를 직접 수동 실행하여 데이터를 최신화할 수 있습니다.

### 1. 공공데이터포털 API 신청
1. [공공데이터포털(data.go.kr)](https://www.data.go.kr/)에 로그인합니다.
2. **"한국천문연구원_특일 정보"** API를 검색한 후 오픈 API 활용 신청을 완료합니다.
3. 상세정보 페이지에서 **일반 인증키 (Decoding 또는 Encoding)**를 복사합니다.

### 2. 로컬 환경 변수 설정
프로젝트 루트 폴더에 `.env` 파일을 생성하고 발급받은 API 키를 입력합니다.
```env
# .env 파일 형식 (.env.example 파일 참조)
KASI_API_KEY=발급받은_공공데이터포털_인증키_입력
```

### 3. 데이터 페처 스크립트 실행
Node.js v20.6+ 환경에서는 네이티브로 환경변수 주입을 지원합니다.
```bash
# package.json에 정의된 스크립트 실행
npm run fetch-holidays
```
실행이 완료되면 자동으로 공공데이터포털에서 최신 특일 정보를 가져와 파싱한 후 `data/holidays.json` 파일을 오버라이트하여 커밋 대기 상태로 만들어 줍니다.

## ☁️ Cloudflare Pages 배포 방법 (초간단 무료 호스팅)

1. [Cloudflare 대시보드](https://dash.cloudflare.com/)에 로그인합니다.
2. **"Workers & Pages"** 메뉴를 선택하고 **"Create" ➡️ "Pages" ➡️ "Connect to Git"**을 탭합니다.
3. 본 프로젝트가 업로드된 GitHub Public 리포지토리를 연결합니다.
4. **빌드 설정(Build Settings):**
   - **Framework preset:** `None` (완전 정적)
   - **Build command:** (비워둠 - 빌드 없음)
   - **Build output directory:** `/` (루트 디렉토리 그대로 배포)
5. **Save and Deploy**를 누르면 끝납니다. 이제 Git 푸시(push)가 일어날 때마다 Cloudflare가 자동으로 몇 초 안에 초고속 정적 배포를 마칩니다.
